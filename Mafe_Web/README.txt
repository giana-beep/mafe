MAFE — PHP + MySQL school project
======================================

NO TERMINAL / NO COMPOSER / NO NPM

1. Copy folder "Mafe_Web" into:
   C:\xampp\htdocs\

2. Open XAMPP.
3. Turn ON Apache and MySQL.
4. Open:
   http://localhost/Mafe_Web/

The database "mafe_web" and tables are created automatically on first load.
No phpMyAdmin import is required.

MAIN FEATURES
- Account register/login
- Skin profile
- Personalized product match score
- Product database + search + filters
- Product detail + ingredient tags
- Ingredient dictionary
- Paste INCI analyzer
- Browser barcode scanner when BarcodeDetector is supported
- Compare up to 4 products
- Routines (AM/PM, frequency, daily log)
- Simple routine conflict warning engine
- Shelves: Liked / Owned / Wishlist / Disliked
- Product reviews
- Community posts
- Local admin product database

IMPORTANT
This is an independent school project inspired by common skincare-app features.
It is NOT connected to Mafe's database/API and does not copy Mafe's proprietary data.
Ingredient analysis is educational and not medical advice.

If images from remote demo URLs do not load offline, replace product image URLs
from the admin/database with local images in uploads/.
